# Smart-Care-Vital-Ai-Your-Personal-Health-Companion
SmartCare: Vital AI is a responsive health companion web app built with HTML, CSS, JS, Bootstrap, PHP &amp; MySQL. Track fitness goals like Fat Burning, Cardio, Yoga &amp; Weight Loss with detailed plans, exercises &amp; tips. Features an AI chatbot via OpenAI API for real-time personalized fitness guidance.
